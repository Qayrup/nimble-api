快速开始
项目介绍
🪶

轻量级

零外部依赖（eventhub），api-service 仅依赖 eventhub。Tree-shaking 友好，按需加载。

🔌

可扩展适配器

内置 fetch 和 uni-app 适配器，实现 RequestAdapter 接口即可接入任意 HTTP 层。

🛡️

类型安全

完整的 TypeScript 类型推导，EventMap 泛型约束事件，TypedApi 生成端点包装器。

🔄

智能重试

可配置的重试策略，支持指数退避和固定延迟，beforeRetry 钩子可中止重试。

⚡

缓存系统

LRU 内存缓存，TTL 过期，SWR (stale-while-revalidate) 模式，标签批量失效。

🪝

钩子管线

beforeRequest → afterResponse → beforeRetry → beforeError，完整的请求生命周期拦截。

📡

事件驱动

基于 EventHub 的事件系统，支持 onSuccess/onError 全局事件订阅和分发。

🧩

Monorepo 架构

npm workspaces 管理，eventhub、api-service、sse-service、api-extend 独立发布，按需组合使用。

📡

SSE 支持

@nimble-api/sse-service 提供原生 SSE 客户端，自动重连、Last-Event-ID、事件路由。

🔁

轮询扩展

@nimble-api/api-extend 提供声明式 poll() 函数，类型安全、可取消、支持 type guard 窄化。
